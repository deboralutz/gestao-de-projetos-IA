# Sistema assistido por IA

Componentes que tornam a IA parte do sistema de trabalho, e não apenas uma ferramenta de perguntas e respostas.

- `fluxos`: sequências de trabalho e pontos de decisão;
- `agentes`: especificações de agentes, ferramentas, limites e aprovações;
- `prompts-operacionais`: instruções versionadas para tarefas recorrentes;
- `automacoes`: integrações e rotinas automatizadas.

Promova para esta pasta apenas o que já tiver sido testado no [`04-laboratorio`](../../04-laboratorio).
