# Lutz PI

Espaço para transformar o aprendizado do curso em um sistema de gestão assistido por IA.

## Fluxo de trabalho de referência

`cliente` → `diagnostico` → `organizacao por IA` → `plano de acao` → `execucao` → `monitoramento` → `entrega` → `documentacao final`

## Áreas

- `01-modelo-operacional`: como a organização trabalha;
- `02-projetos`: instâncias concretas de trabalho, baseadas no template de ciclo de vida;
- `03-processos`: procedimentos repetíveis;
- `04-sistema-assistido-ia`: fluxos, agentes, prompts e automações;
- `05-base-conhecimento`: conhecimento de apoio, com atenção a sigilo e atualidade;
- `06-indicadores`: métricas para acompanhar saúde, qualidade e capacidade.
