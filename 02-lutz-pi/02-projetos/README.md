# Projetos

Cada projeto deve ter sua própria pasta e seguir, quando aplicável, as seis pastas do [`00-template-projeto`](00-template-projeto).

Sugestão de nome: `AAAA-nn-nome-curto-do-projeto`.

Não coloque aqui credenciais, documentos pessoais ou arquivos confidenciais de clientes sem a proteção e a autorização adequadas.
