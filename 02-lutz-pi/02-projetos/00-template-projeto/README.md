# Template de projeto

Duplique esta pasta para iniciar um novo projeto. Preencha primeiro o contexto, o objetivo, os interessados e os critérios de sucesso.

## Fases

1. `01-iniciacao`: problema, objetivo, justificativa, escopo inicial e stakeholders;
2. `02-planejamento`: EAP/WBS, cronograma, recursos, comunicação e riscos;
3. `03-execucao`: tarefas, reuniões, decisões e entregas em andamento;
4. `04-monitoramento`: planejado versus realizado, indicadores, desvios e ações corretivas;
5. `05-encerramento`: aceite, relatório final, retrospectiva e lições aprendidas;
6. `06-documentacao`: versão consolidada, referências e materiais de continuidade.

## Controle humano

Toda sugestão produzida por IA deve ser revisada antes de virar decisão, comunicação externa ou entrega ao cliente.
