# Módulo 3 — Gestão de riscos com IA

## Foco

Identificar riscos, analisar probabilidade e impacto, priorizar respostas e monitorar sinais de alerta com apoio de IA.

## Aplicação sugerida

Construir uma matriz de riscos para um processo de propriedade intelectual, incluindo proprietário, resposta, gatilho e periodicidade de revisão.
