# Módulo 2 — IA no planejamento de projetos

## Foco

Usar IA para transformar objetivos em escopo, EAP/WBS, cronograma, orçamento, comunicação e plano de execução revisáveis.

## Aplicação sugerida

Criar um plano inicial para um projeto da Lutz PI e validar cada decisão com critérios humanos, premissas e restrições reais.
